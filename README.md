# Pixora 📸

Pixora is a full-stack image sharing platform where users can upload, store, and view images.  
The project is built to understand real-world backend development, API creation, database management, and file storage.

## 🚀 Features

- Upload images
- Store image details
- Display uploaded images
- Create and manage posts
- Backend API integration
- Responsive user interface

## 🛠️ Tech Stack

### Frontend

- React.js
- HTML
- CSS
- JavaScript

### Backend

- Node.js
- Express.js

### Database

- MongoDB

### Image Storage

- Cloudinary

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone https://github.com/pkppwe23-sketch/Pixora-.git


2. Install backend dependencies

cd backend
npm install

3. Install frontend dependencies

cd frontend
npm install

▶️ Run the Project

a.Start Backend

cd backend
npm start

b.Start Frontend

cd frontend
npm run dev
```
